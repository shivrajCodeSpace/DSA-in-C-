# DSA_in_C++
DSA in C++ helps us learn how to store and manage data properly. It includes data structures like arrays, stacks, queues, trees, and graphs. It also teaches algorithms for searching, sorting, and solving problems. Learning DSA improves programming logic and problem-solving skills.

## What is a Data Structure?

A data structure is a way of organizing and storing data so that it can be used efficiently.

It helps us to:
- store data in an organized way
- access data quickly
- insert and delete data easily
- solve problems in a better way

## Types of Data Structures

### 1. Linear Data Structures
These store data in a sequence.

- Array
- Stack
- Queue
- Linked List

### 2. Non-Linear Data Structures
These store data in a branching or hierarchical way.

- Tree
- Graph

## Why Data Structures are Important

Data structures help us write efficient programs and solve real-world problems easily.

## How to run a C++ file from the project root:

- If the file is in the root folder:

```bash
g++ index.cpp -o index && ./index
```

- If the file is in a subfolder, you can compile it by giving the relative path:

```bash
g++ "FolderName/FileName.cpp" -o "FolderName/FileName" && "./FolderName/FileName"
```

- You can also compile and run from the subfolder:

```bash
cd "FolderName" && g++ FileName.cpp -o FileName && ./FileName
```
