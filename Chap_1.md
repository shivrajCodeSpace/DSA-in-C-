# Chapter 1: Pseudo Code

## Definition

Pseudo code is a simple, human-readable way to describe the steps of an algorithm without using the strict syntax of a programming language. It uses plain language and structured formatting to explain logic, control flow, and operations in a way that is easy to understand and later translate into actual code.

## Purpose

- Helps plan algorithms before coding
- Focuses on logic rather than syntax
- Makes it easier to communicate ideas with others
- Serves as a bridge between problem solving and programming

## Example Structure

1. Start
2. Input data
3. Process data using clear steps
4. Output result
5. End
